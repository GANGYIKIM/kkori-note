# R0 화면 구조

- 시작: 2026-11-02
- 근거: `docs/prd/R0.md`
- 목표: 화면 폭 구간과 폭 규칙(ADR-0014)을 메인·채팅·설정에 적용하고, 목록 오름차순·채팅 화면 전체·진행 중 띠 위치·데이터 상태 화면·오버레이 스크롤바를 만든다.
- 범위 밖: 실제 저장소에서 불러오기와 R0-6 연결(R1 하위 작업 5), 설정 내용(R7·R5·R10), 320px 미만에서 고정 요소의 폭
- 블로킹 질문: 없음

## 요구사항별 개발

PRD의 하위 요구사항마다 한 줄. ID와 짧은 이름만 적고 PRD 문장을 옮기지 않는다. 빠지거나 PRD에 없는 ID가 있으면 `tests/requirements.test.ts`가 실패한다.

| 하위 요구사항 | 어떻게 만드나 | 하위 작업 | 확인 |
|---|---|---|---|
| R0-1 화면 구성 | 메인 왼쪽 칸·설정을 헤더 / 본문(`overflow-y-auto`) / 하단으로 나눈 `h-dvh` 세로 배치. 화면 내용은 R7·R5·R10 | 3 | 수동 확인, R7, R5, R10 |
| R0-2 기록 목록 | `groupByLocalDate` 오름차순(하루 전체 기록은 그날 맨 아래), 맨 아래에서 열기, 새 기록 따라가기, 시각 자리 "종일". `OngoingEpisodeBar`를 입력창 위로(메인 하단, 채팅 시트, PC 채팅 칸) | 2, 4 | 테스트 + 수동 확인 |
| R0-3 채팅 | `BottomSheet`가 열려 있는 동안 문서 스크롤 잠금, `full` 시트는 창 폭 100%·안쪽 92% | 2 | 수동 확인 |
| R0-4 화면 폭 구간 | 1단 `w-[92%]`, PC 2단 틀 `w-[92%] max-w-[1200px]`, 칸 `minmax(0,1fr)`·`min(40%,420px)`, 설정 `w-[92%] max-w-[672px]` | 1 | 수동 확인 |
| R0-5 최소 폭 | `body` `min-w-80` | 1 | 수동 확인 |
| R0-6 데이터 상태 | 불러오기 상태 타입, 목록·채팅 회색 자리, 다시 시도가 있는 오류 자리. 연결은 R1 하위 작업 5 | 5 | `/preview` 수동 확인, 연결 후 R1 |
| R0-7 오버레이 스크롤바 | 전역 CSS로 기본 스크롤바 숨김, `common/ScrollArea`를 본문 스크롤 영역(메인, 설정, PC 두 칸, 시트 본문)에 씀 (ADR-0015) | 6 | 테스트 + 수동 확인 |

## 하위 작업

수락 기준 묶음 하나가 하위 작업 하나다. 위에서부터 한다. 시작하면 하위 문서를 링크하고, 끝나면 체크한다.

- [x] 1. [폭 규칙 적용](width-rules.md): 메인 1단·PC 2단·헤더·하단 입력창·설정을 ADR-0014 값으로, 320px 최소 폭 — 채우는 수락 기준: R0-4.1, R0-4.2, R0-4.3, R0-5.1
- [x] 2. [채팅 스크롤 잠금과 진행 중 띠 위치](chat-sheet-and-ongoing-bar.md): 뒤 목록 스크롤 잠금, 진행 중 띠를 입력창마다 바로 위로. 채팅 시트 폭은 다시 손봄 — 채우는 수락 기준: R0-2.4, R0-3.3
- [x] 3. [헤더 고정과 본문 스크롤](fixed-header-scroll-body.md): 메인 왼쪽 칸과 설정을 헤더 / 본문 / 하단으로 나누고 스크롤은 본문에만 — 채우는 수락 기준: R0-1.1
- [x] 4. [목록 오름차순](ascending-list.md): 날짜·기록 오름차순, 하루 전체 기록은 "종일"·그날 맨 아래, 맨 아래에서 열기, 새 기록 따라가기 — 채우는 수락 기준: R0-2.2, R11 "종일" 표시
- [x] 5. [데이터 상태 화면](load-states.md): 상태 타입과 회색 자리·오류 자리 컴포넌트, 미리보기 변형 — 채우는 수락 기준: 없음(R0-6.1~6.3은 R1 하위 작업 5에서 연결 후 체크)
- [x] 6. [오버레이 스크롤바](overlay-scrollbar.md): 기본 스크롤바 숨김, 막대 컴포넌트(보이기·1초 뒤 사라지기·끌기), 모든 스크롤 영역에 적용 — 채우는 수락 기준: R0-7.1, R0-7.2, R0-7.3, R0-7.4
