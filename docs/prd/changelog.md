# PRD 변경 내역

PRD(`docs/PRD.md`, `docs/prd/`)를 고칠 때 맨 아래에 한 줄씩 추가한다.

- v0.2 변경: 텍스트 입력을 1순위로, 음성은 P2 보조로 변경 / 표현 정규화(R8) 추가 / 날씨 입력(P2)·날씨 자동 연동(P4) 추가
- v0.3 변경: 기술 스택 확정 / Vercel 배포를 필수로 변경하고 셋업 단계에서 먼저 배포 / 요청 횟수 제한 등 비용 방어(R9) 추가 / 일정 재배치(셋업 미착수 기준)
- v0.4 변경: 사진·서류 첨부를 P2로 내림 / 데모 데이터를 P1(R10)으로 올림 / 모호한 입력은 칩에서 수정(채팅으로 칩 고치기는 P2) / 시간대·날짜 경계 규칙(R2) / 에피소드 닫기 규칙(R1) / 사전 우선 파싱으로 LLM 호출 생략(R1) / 질문 분류와 위험 키워드 강제 판정(R4) / 체중 미입력 시 판정(R6) / 모델 확정(ADR-0001) / 셋업 완료 반영
- v0.5 변경: 화면 구조 신설(R0: 하단 탭 없음, 메인 = 기록 목록, 입력창 → 채팅) / 채팅 하나에서 기록·상담을 앱이 나눔, 애매하면 기록(R1) / 칩 즉시 저장 + 되돌리기(R1) / "조용한 기록"을 "짧은 기록 응답 + 위험 상황 예외"로(R3) / 근거 기록 카드는 코드가 만듦, 기록+상담 응답 순서(R4) / 기록 경로 위험 안내와 등급 × 모드 고정 문장(R6) / 데이터 모델 추가(R7)
- 2026-10-30 문서 구조: 요구사항을 영역별 파일(`docs/prd/`)로 나누고 변경 내역·열린 질문·지표(`docs/metrics.md`)를 분리. 날짜별 일정은 `docs/PLAN.md`로 일원화. Goals의 수치는 지표 ID로 가리킴. 요구사항 내용은 바꾸지 않음.
