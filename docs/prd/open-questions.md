# 열린 질문

아직 정하지 못한 것. 블로킹 질문에 걸린 값은 지어내지 말고 묻는다. 풀리면 줄을 지우고 결과는 해당 R, ADR, `docs/research/` 중 맞는 곳에 남긴다.

| 질문 | 막힌 R | 담당 | 구분 |
|---|---|---|---|
| 에피소드로 열 수 있는 종류는 무엇인가 (지금은 절뚝임·발작·천둥 떨림 고정. 다른 종류도 열 수 있게 할지, 종류 편집(P2)에서 사용자가 정하게 할지) | R11 | 본인 | 비블로킹 (R11 계획 때 논의) |
| R11 기본 종류별 항목 표 다시 검토 (식사 양·사료 이름, 산책 시간, 절뚝임 부위 등 빈 곳 포함. R1 계획 때 초안만 둠. 코드의 정의는 초안이 아니라 기존 값 목록을 옮긴 것이라 다른 점이 있다: 혈변·점액을 `blood_mucus` 하나로 둠, 초콜릿 종류를 조건 없이 보임. 핵심 항목도 함께 검토, R1 계획 때 배변 = 상태, 주워 먹음 = 음식만 둠) | R11 | 본인 | 비블로킹 (R11 계획 때 논의) |
| 수정 시트에서 하루 전체 기록(`timePrecision: "day"`)을 어떻게 고를지 | R1 | 본인 | 비블로킹 (R1-6 검토 때 논의) |
| 설계 원칙 5 "새 메시지를 처리할 때 이전 대화를 LLM에 넣지 않는다"를 유지할지. 채팅으로 칩 고치기(P2, "아니, 바보야" 같은 부정에 직전 기록을 다시 해석)와 상담의 앞뒤 맥락에 이전 대화가 필요할 수 있다. 바꾸면 ADR을 쓰고 CLAUDE.md 원칙을 고친다 | R1, R4 | 본인 | 비블로킹 (채팅으로 칩 고치기 계획 때 논의) |
| 칩이 다 채워져도 코드 결과를 LLM이 매번 검사하는 방식으로 바꿀지 (설계 원칙 4 변경, 요청 수 증가로 R9 비용 방어와 함께 판단). M5 데이터를 보고 정한다 | R1, R8 | 본인 | 비블로킹 (M5 측정 후 논의) |
| 하루 전체 기록의 횟수(예: 배변 "하루 3회")를 횟수 집계에서 기록 1건으로 셀지 횟수 값으로 셀지 | R4 | 본인 | 비블로킹 (R4 계획 때 논의) |
| 에피소드 자동 종료 기준 시간(발작·절뚝임·천둥 떨림 각각)과 출처. 종류 정의(R11)의 속성으로 둔다 | R12, R11 | 본인(자료 조사) | 블로킹(R12 자동 종료) |
| 발작이 열린 채 5분이 지나면 위험 안내를 띄울지, 자동 종료로 지속시간이 "모름"인 발작을 위험 판단에서 어떻게 볼지 | R6 | 본인 | 비블로킹 |
| 모드별 병원 권유 기준값(설사 횟수, 지속시간 등)의 수의학 출처 | R5 | Claude 초안 → 본인 확정 | 블로킹 |
| 초콜릿 외 위험 음식의 임계값과 출처 | R6 | 본인 | 블로킹(R6 확장 전) |
| 한국어 분류 품질이 파싱 모델(Luna)로 충분한지 | R8 | 개발 | 블로킹(표현 사전 테스트로 확인) |
| 배변 상태 값 목록 세분화 여부 (수의학 변 점수표 등 출처 확인 필요, 현재는 5~6단계로 시작) | R8 | 본인(자료 조사) | 비블로킹 |
| 한국 중독 상담/응급 연락처의 정확한 안내 문구 | R6 | 본인 | 비블로킹 |
