# R11. 기록 종류와 항목

> 색인: `docs/PRD.md` / 자주 함께 보는 R: R8

## 사용자 스토리

- (P2) 보호자로서, 사진과 병원 검사 서류를 기록에 첨부하고 싶다. 병원에서 다시 보여주기 위해서다.
- (P2) 보호자로서, 그날 날씨를 기록에 남기고 싶다. 천둥 떨림이나 비 오는 날의 컨디션을 나중에 함께 보기 위해서다.

## 요구사항 (P1)

- 기록 종류, 종류별 항목, 항목의 값 목록은 나중에 사용자가 고칠 수 있는 설정으로 다룬다. 이번에는 아래 기본값만 제공하고 편집 화면은 두지 않는다.
- 값 목록에 값이 추가되거나 항목이 늘어도 이미 저장된 기록은 그대로 유지된다.
- 모든 기록에는 시각(추정 여부 포함)과 원문이 있다.
- 기본 종류와 항목 (초안, R11 계획 때 다시 검토):

| 종류 | 구분 | 항목 |
|---|---|---|
| 배변 | 순간 | 상태(딱딱함·정상·무름·설사·혈변·점액·기타), 횟수 |
| 식사 | 순간 | 상세(텍스트) |
| 간식 | 순간 | 상세(간식 이름) |
| 산책 | 순간 | 상세(좋았던 일) |
| 주워 먹음 | 순간 | 음식(위험 음식 5개 + 기타), 초콜릿 종류(음식이 초콜릿일 때만), 양(g), 상세(텍스트) |
| 메모 | 순간 | 상세(텍스트) |
| 절뚝임 | 에피소드 | 시작, 종료/지속시간, 강도(약·중·강) |
| 발작 | 에피소드 | 시작, 종료/지속시간, 강도 |
| 천둥 떨림 | 에피소드 | 시작, 종료/지속시간, 강도 |

- 수락 기준
  - [ ] 기본 9개 종류가 위 항목으로 칩에 표시되고 저장된다.
  - [ ] 값 목록에 값을 추가해도 기존 기록이 그대로 열리고 집계된다.

## 나중에

- (P2) **기록 종류 편집**: 가계부 앱처럼 사용자가 종류·하위 분류·입력 항목·값 목록을 추가하고 고친다. LLM이 입력에 맞는 종류·항목을 제안하고 중복 항목을 걸러 준다. 사용자가 추가한 값(예: 주워 먹음 > 음식 > "기름진 음식")에 위험 규칙을 붙여 `assess()`가 판정에 쓰게 한다. 기본 위험 규칙(초콜릿 계산 등)은 사용자가 지우거나 바꾸지 못한다. (R11)
- (P2) **사진·서류 첨부**: 기록에 사진과 병원 검사 서류를 첨부하고 메인 기록 목록에서 본다. IndexedDB에 저장하며 AI가 해석하지 않는다. 데이터 모델의 `attachmentIds`는 P1부터 비어 있는 필드로 둔다.
- (P2) **날씨 수동 입력**: 기록의 부가 필드. 값 목록 `맑음 / 흐림 / 비 / 눈 / 천둥·번개 / 폭염 / 한파`. "천둥 쳐서 덜덜 떨어" 같은 문장에서 날씨와 행동을 함께 추출해 한 칩에 표시한다. 일별 요약에 날씨 한 줄을 추가해 상담에서 날씨와 기록을 함께 근거로 쓸 수 있게 한다. (R8과 같은 정규화 방식 사용)
- (P3) **일기 기록 입력**: 별도 화면 없이 채팅으로 "일기" 종류를 기록 (발작 기록과 같은 방식).
- (P4) **날씨 자동 연동**: 기록 시각과 위치로 기상 API에서 날씨를 자동으로 붙인다. 위치 권한, 외부 API 키, 호출 한도 확인 필요 (API는 착수 시 조사).
