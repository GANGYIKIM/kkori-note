# R5. 모드 (과보호 / 중립 / 무던, 기본 중립)

> 색인: `docs/PRD.md`

## 사용자 스토리

- 보호자로서, 내 성향에 맞게 과보호/중립/무던 중 상담 태도를 고르고 싶다. 병원 권유 기준과 안내의 양이 내 불안 수준에 맞았으면 한다.

## 요구사항 (P1)

- 내용 차이는 **설정값(코드)**, 말투 차이는 **프롬프트**로 처리한다.

| | 과보호 | 중립 | 무던 |
|---|---|---|---|
| 병원 권유 기준 | 낮음 | 중간 | 높음 |
| 관찰 항목 | 많음 | 핵심 3개 | 핵심 1~2개 |
| 원인 후보 | 드문 원인까지 | 흔한 원인 + 주의 1개 | 흔한 원인 위주 |
| 말투 | 걱정스럽고 조심스럽게 | 차분하고 객관적으로 | 느긋하고 가볍게 |

- 구체적 기준값은 설정 파일로 분리하고, **수의학 자료로 출처 확인 후 확정**한다. Claude가 공개 수의학 자료(Merck Veterinary Manual, VCA 등)로 출처를 단 초안을 만들고, 본인이 검토해 확정한다. 출처는 `docs/research/`에 남긴다.

  - [ ] 모드를 바꿔도 기록 조회 결과(숫자)는 동일하다.
