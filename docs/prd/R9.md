# R9. 배포와 비용 방어 (Vercel)

> 색인: `docs/PRD.md`

## 요구사항 (P1)

- 배포 주소는 제출 필수 항목이다. **셋업 단계에서 "빈 화면 + LLM 호출 1개" 상태로 먼저 Vercel에 배포**하고, 이후 GitHub 푸시마다 자동 배포되게 해서 마지막 날 배포 사고를 막는다.
- OpenAI API 키는 Vercel 환경변수로만 관리한다. 코드와 GitHub 저장소에는 올리지 않고, `.env*` 파일이 `.gitignore`에 포함되어 있는지 셋업 시 확인한다.
- **요청 횟수 제한(필수)**: LLM을 호출하는 모든 API Route는 `guardLlmRequest`를 통과한다. 기본값은 IP당 하루 30회, 서버 전체 하루 500회, 입력 500자이며 환경변수로 바꿀 수 있다. 한도 초과 시 사용자에게 이해하기 쉬운 안내 문구를 보여준다.
- 한계: 횟수는 서버 메모리에 저장되므로 Vercel에서는 인스턴스마다 따로 세고 재시작 시 초기화된다. 그래서 실제 지출 상한은 선불 크레딧과 OpenAI 프로젝트 한도가 맡고, 메모리 제한은 1차 방어로 둔다. 외부 저장소(Redis 등) 도입은 남용이 관찰되면 검토한다.
- OpenAI는 충전식(선불) 크레딧으로 사용해 지출 상한을 갖는다. 사용 한도 설정은 보조 안전장치로 확인한다.
- (선택) 심사자용 접근 코드.
- 수락 기준
  - [ ] Vercel 배포 주소에서 기록 입력과 상담이 동작한다.
  - [ ] GitHub 저장소 전체에 API 키가 포함되어 있지 않다.
  - [ ] 한도를 초과한 요청은 LLM을 호출하지 않고 안내 문구를 반환한다.
  - [ ] 너무 긴 입력은 LLM 호출 전에 거부된다.
