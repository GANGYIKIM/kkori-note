# 안전 판단

> 상위: `docs/PRD.md` / 자주 함께 보는 R: R3(짧은 기록 응답), R4(상담), R5(모드)

## 사용자 스토리

- 보호자로서, "초콜릿 먹었는데 괜찮아?"처럼 위험 상황에서 일관되고 안전한 안내를 받고 싶다.

## 요구사항 (P1)

**R6. 안전 판단 `assess()` (최소 범위)**
- LLM 문장 생성 전에 코드가 위험 등급을 결정한다: 🔴 고위험 / 🟡 경계 / 🟢 저위험. LLM은 등급에 맞춰 문장만 쓰고, 출력 검사에서 등급과 모순되는 표현(예: 🔴에 "괜찮아요")을 거른다.
- 🔴: 모든 모드가 동일하게 "지금 동물병원에 연락"을 안내한다. 🟡: 모드별로 다르되 모든 모드에 최소 "병원에 전화 상담"을 포함한다. 🟢: 모드는 말투와 관찰 안내에 영향을 주고, 관찰 기준(증상은 보통 6~12시간 뒤 나타날 수 있음)을 항상 안내한다.
- 앱은 구토 유도 방법이나 투약량을 안내하지 않는다. 대신 시간이 중요함을 알리고 병원 연락을 안내한다.
- v1 범위: 초콜릿 독성 계산(체중, 종류, 양)과 고정 응답 몇 가지(포도·건포도, 자일리톨, 마카다미아, 양파·마늘). 한국 중독 상담 연락처는 미확인이라 "가까운 24시간 동물병원"으로 안내한다.
- 정보가 부족하면 보수적으로 판정한다: 체중이 프로필에 없거나, 초콜릿 종류·양을 알 수 없으면 계산하지 않고 🔴로 판정하고, 무엇을 알면 더 정확해지는지 함께 안내한다. 사용자가 양·종류를 알려주거나 칩에서 고치면 다시 판정한다(등급이 내려갈 수 있음).
- `assess()`는 순수 함수다(입력: 기록 또는 질문에서 뽑은 사실 + 프로필 + 최근 에피소드, 출력: 등급과 이유 코드). 모드는 입력에 넣지 않는다.
- **두 경로에서 호출된다**: 상담 질문(R4)과 위험 규칙에 걸린 기록(R3 예외).
- **기록 경로와 고정 응답의 문장은 코드의 고정 문장**이다. 등급 × 모드별 문장 표를 코드에 두고, LLM을 쓰지 않는다. 모드 간 모순을 테스트로 확인하기 위해서다. LLM 문장(+ 출력 검사)은 상담의 자유 답변에만 쓴다.
- 등급 × 모드 문장 예시 (초콜릿 기록)

| 등급 | 과보호 | 중립 | 무던 |
|---|---|---|---|
| 🔴 (많이 먹음, 또는 양·종류·체중 모름) | 모든 모드 동일: "지금 가까운 동물병원(야간이면 24시간 병원)에 연락해 주세요. 시간이 중요해요." + 모를 때는 "어떤 초콜릿을 얼마나 먹었는지 알려주시면 위험도를 다시 계산해 드릴게요." | ← | ← |
| 🟡 | "빨리 병원에 전화해 상담받아 보세요." | "병원에 전화로 상담받아 보시길 권해요." | "다니시는 병원에 전화로 한번 물어보세요." |
| 🟢 | "지금은 위험 수치 아래예요. 그래도 6~12시간 동안 구토·설사·흥분이 있는지 지켜봐 주시고, 걱정되면 병원에 연락해 주세요." | "위험 수치 아래예요. 6~12시간 동안 구토·설사·흥분을 지켜봐 주세요." | "이 양이면 크게 위험하지 않을 수 있어요. 6~12시간 정도 지켜보시고, 다니시는 병원에 문의해 보시면 더 좋아요." |
- 면책 화면: 앱은 진단이 아니며 응급 시 병원에 연락하라고 안내한다.
- 수락 기준
  - [ ] 평가 케이스 약 20개(체중 × 종류 × 양 × 경과 시간)에서 세 모드 모두 🔴 케이스가 같은 결론을 낸다.
  - [ ] 🟡 케이스는 모든 모드에 병원 전화 상담 안내가 포함된다.
  - [ ] 🔴 응답에 안심 표현이 없고, 구토 유도·투약량 안내가 없다.
  - [ ] 발작 5분 초과 같은 에피소드 기반 고위험 규칙은 무던 모드에서도 동작한다.
  - [ ] 체중 미입력 상태의 초콜릿 질문은 🔴로 판정된다.
  - [ ] "초콜릿 먹었어"(양 모름) 기록은 무던 모드에서도 🔴 문장이 나오고, 이어서 양·종류를 알려주면 다시 판정된다.

## 나중에

- (P3) **웹 검색 연동**: 위험 상황 답변에 최신 검색 반영. 허용 출처 목록, 출처 표시, 검색 결과는 등급을 올리기만 하고 내리지 않음, 실패 시 고정 응답.

## 참고 (근거 자료 메모)

- 초콜릿 독성 기준은 Merck Veterinary Manual의 메틸잔틴 함량·임계값(약 20 / 40~50 / 60 mg/kg 이상)을 참고했다. 값은 제품에 따라 달라지는 근사치이며 개발 시 재확인한다.
- 이 앱은 의료 진단 도구가 아니며, 모든 안전 문구는 "병원 상담 권유" 수준으로 제한한다.
