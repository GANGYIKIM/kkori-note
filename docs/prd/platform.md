# 데이터와 운영

> 상위: `docs/PRD.md` / 자주 함께 보는 R: R0(화면 구조), R1(기록 저장)

## 사용자 스토리

- 심사자/방문자로서, 샘플 기록을 한 번에 불러와 앱의 기록 목록과 상담을 바로 체험하고 싶다.

## 요구사항 (P1)

**R7. 프로필, 저장, 기반**
- 강아지 프로필(이름, 나이, 체중, 특이사항)과 설정(모드)을 저장한다.
- 저장은 브라우저 로컬(IndexedDB)이며, `getDog / saveEntry / listEntries` 같은 저장소 인터페이스 뒤에 숨긴다. 데이터는 `dogId` 기준.
- 기록 데이터 모델에 `weather`를 비어 있는 선택 필드로 미리 포함한다. (입력·자동 연동은 P2·P4)
- 데이터 모델 추가 필드: 기록에 `timeEstimated`(시각을 추정했는지), `isDemo`(샘플 기록인지), 위험 음식 칸(음식 값 목록, 초콜릿 종류, 양 g). 상담 메시지는 **채팅 메시지**로 넓혀 기록과 상담을 함께 담고, 연결된 기록 id·근거 카드·위험 등급을 저장한다.
- LLM 호출은 서버 API Route에서만 한다 (API 키는 브라우저에 노출하지 않음).
- 모바일 우선 반응형. 화면 구조는 R0.
- 수락 기준
  - [ ] 새로고침 후에도 프로필과 기록이 유지된다.
  - [ ] 저장소 구현을 교체해도 화면 코드는 바뀌지 않는다.
  - [ ] `weather` 필드가 비어 있어도 모든 화면과 집계가 정상 동작한다.

**R9. 배포와 비용 방어 (Vercel)**
- 배포 주소는 제출 필수 항목이다. **셋업 단계에서 "빈 화면 + LLM 호출 1개" 상태로 먼저 Vercel에 배포**하고, 이후 GitHub 푸시마다 자동 배포되게 해서 마지막 날 배포 사고를 막는다.
- OpenAI API 키는 Vercel 환경변수로만 관리한다. 코드와 GitHub 저장소에는 올리지 않고, `.env*` 파일이 `.gitignore`에 포함되어 있는지 셋업 시 확인한다.
- **요청 횟수 제한(필수)**: LLM을 호출하는 모든 API Route는 `guardLlmRequest`를 통과한다. 기본값은 IP당 하루 30회, 서버 전체 하루 500회, 입력 500자이며 환경변수로 바꿀 수 있다. 한도 초과 시 사용자에게 이해하기 쉬운 안내 문구를 보여준다.
- 한계: 횟수는 서버 메모리에 저장되므로 Vercel에서는 인스턴스마다 따로 세고 재시작 시 초기화된다. 그래서 실제 지출 상한은 선불 크레딧과 OpenAI 프로젝트 한도가 맡고, 메모리 제한은 1차 방어로 둔다. 외부 저장소(Redis 등) 도입은 남용이 관찰되면 검토한다.
- OpenAI는 충전식(선불) 크레딧으로 사용해 지출 상한을 갖는다. 사용 한도 설정은 보조 안전장치로 확인한다.
- (선택) 심사자용 접근 코드.
- 수락 기준
  - [ ] Vercel 배포 주소에서 기록 입력과 상담이 동작한다.
  - [ ] GitHub 저장소 전체에 API 키가 포함되어 있지 않다.
  - [ ] 한도를 초과한 요청은 LLM을 호출하지 않고 안내 문구를 반환한다.
  - [ ] 너무 긴 입력은 LLM 호출 전에 거부된다.

**R10. 데모 데이터**
- 설정 화면의 "샘플 기록 불러오기" 버튼으로 약 2주치 샘플 기록(배변, 식사·간식, 산책, 주워 먹은 것, 발작·절뚝임·천둥 떨림 에피소드)을 넣는다. 심사자가 배포 주소를 처음 열었을 때와 시연 영상 촬영용이다.
- 샘플 기록의 시각은 불러오는 순간을 기준으로 상대 시각으로 만든다(항상 "최근 2주"가 되게).
- 샘플 기록은 `isDemo` 표시를 붙여 한 번에 지울 수 있다. 기록이 비어 있을 때 메인의 빈 상태 화면에서도 버튼을 보여준다.
- 수락 기준
  - [ ] 빈 상태에서 버튼 한 번으로 메인 기록 목록과 상담("지난주 배변 어땠어?", "발작 기록 모아서 보여줘")을 바로 체험할 수 있다.
  - [ ] 샘플 기록만 지우는 기능이 사용자가 직접 남긴 기록은 지우지 않는다.

## 나중에

- (P3) 로그인 + 초대 기반 한 마리 접근, 기기 간 동기화, 모바일 앱 출시.

## 기술 스택

| 영역 | 선택 | 비고 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | API Route로 LLM 키를 서버에 숨김 |
| 스타일 | Tailwind | 모바일 우선 |
| 스키마/값 목록 | Zod | LLM 출력 검증, 칩 UI, 집계가 같은 값 목록을 참조 |
| LLM | OpenAI SDK (구조화 출력) | 파싱 `gpt-6-luna`(추론 none), 상담 `gpt-6.1-terra`(추론 low). 근거는 `docs/adr/0001-llm-model-selection.md`. 모델명은 환경변수로만 지정 |
| 로컬 저장 | IndexedDB (Dexie 등 얇은 래퍼) | 저장소 인터페이스 뒤에 숨김 |
| 상태 관리 | React 기본 상태 | 전역 상태 라이브러리는 쓰지 않는다(공유 데이터의 원본은 IndexedDB). 근거는 `docs/adr/0003-no-global-state-library.md` |
| 테스트 | Vitest | 집계, 시각 파서, 표현 사전, 안전 평가 케이스 |
| 배포 | Vercel + GitHub 연동 | R9 참고 |

- GraphQL/Apollo는 사용하지 않는다(서버 데이터 없음, Route Handler로 충분).
- 확장 고려(로그인, 앱 출시): 저장소 인터페이스, `dogId` 기준 데이터 모델, 서버 API Route 분리로 이후 서버 저장·인증·앱 클라이언트를 붙일 수 있게 해둔다. 구체적인 방식은 확장 시점에 결정한다.
