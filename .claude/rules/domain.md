# 도메인 로직 규칙

- 이 폴더는 UI·저장소·네트워크와 무관한 순수 함수만 둔다. React, Dexie, OpenAI를 import하지 않는다.
- 함수마다 같은 폴더에 `*.test.ts` 단위 테스트를 둔다. 시각 파서, 키워드 사전, 의도 나누기, 집계, `assess()`는 테스트 없이 끝내지 않는다.
- 현재 시각과 시간대는 인자로 받는다. 함수 안에서 `new Date()`나 `Date.now()`를 부르지 않는다.
- 기록 종류·항목·값 목록은 `kinds.ts`에만, 종류와 무관한 값 목록은 `values.ts`에만 둔다(ADR-0012). 다른 파일에서 같은 목록을 문자열로 다시 쓰지 않는다. 칩 값은 이 목록에서만 고르고, 목록 밖은 `기타`로 두고 원문을 남긴다.
- 시각은 UTC ISO 문자열로 저장한다(문자열 비교로 기간 조회). "어제", "지난주", 일별 집계의 하루 같은 날짜 개념은 기기 현지 시간대로 계산한 뒤 UTC로 바꾼다.
- 강아지 이름이 음식 이름과 겹칠 수 있다(예: "초코"). 사전과 의도 나누기는 프로필 이름을 기록 내용으로 보지 않는다.
- 외부 입력(LLM 출력, 저장소에서 읽은 값)의 모양은 `types.ts`의 Zod 스키마로 검증한다.
- 모드별 기준값과 위험 음식 임계값은 `docs/research/`에서 확정된 값만 쓴다. 출처 없는 숫자를 넣지 않는다.
